# Ресурсы системы
Напишите программу или однострочник, который покажет суммарный размер всех смонтированных персистентных разделов и размер tmpfs по умолчанию (без указания опций size и nr_blocks).

Например, если у нас суммарный размер всех смонтированных персистентных разделов равен 300 гибибайт и размер tmpfs по умолчанию равен 12 гибибайт, скрипт должен вывести:
```
322122547200
12582912
```
Задача может быть решена частично (например, можно узнать только суммарный размер всех смонтированных персистентных разделов или размер tmpfs по умолчанию), тогда вы получите за решение часть баллов. В этом случае достаточно просто вернуть одно полученное число. Используйте информацию из /proc, потому что каких-то специфичных утиллит на тестовой машине может не быть.
